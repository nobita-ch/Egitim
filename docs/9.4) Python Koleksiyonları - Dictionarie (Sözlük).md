Python'da **Sözlük (`dict`)**, verileri **`anahtar: değer` (`key: value`)** çiftleri halinde depolayan haritalama (_mapping_) veri yapısıdır.

- **Sıralıdır (Ordered):** Python 3.7+ sürümlerinden itibaren elemanlar eklenme sırasını korur.
    
- **Değiştirilebilirdir (Mutable):** Sözlük oluşturulduktan sonra eleman eklenebilir, güncellenebilir veya silinebilir.
    
- **Yinelenen Anahtarlara İzin Vermez:** Her anahtar benzersiz (_unique_) olmalıdır. Aynı anahtar tekrar tanımlanırsa eski değerin üzerine yazılır.
    
- **Hızlı Erişim (O(1)):** Elemanlara indeks numarasıyla değil, doğrudan anahtar ismiyle erişilir.
    
- **Anahtar Kısıtlaması (Hashable):** Sözlük anahtarları yalnızca değiştirilemez türlerden (`str`, `int`, `float`, `tuple`, `frozenset`) oluşabilir. Liste (`list`), küme (`set`) veya sözlük (`dict`) anahtar **yapılamaz**. Değerler (_values_) ise her veri tipinde olabilir.
    

## 1. Sözlük Tanımlama Yöntemleri

```Python
# Süslü parantez ile standart tanımlama:
cihaz = {
    "marka": "Dell",
    "ram_gb": 16,
    "ssd_takili": True,
    "portlar": ["USB-C", "HDMI", "Ethernet"]
}

# dict() kurucu fonksiyonu ile tanımlama:
ayarlar = dict(tema="karanlik", bildirimler=True, zaman_asimi=30)

# Boş sözlük oluşturma:
bos_sozluk_1 = {}
bos_sozluk_2 = dict()

# Eleman sayısını (anahtar adedini) öğrenme:
print(len(cihaz))  # 4
```

## 2. Değerlere Erişme: `[]` vs `get()`

```Python
sunucu = {
    "ip": "192.168.1.1",
    "port": 8080,
    "durum": "aktif"
}

# 1. Köşeli Parantez ile Erişim:
print(sunucu["ip"])  # "192.168.1.1"
# print(sunucu["dns"]) # HATA! KeyError fırlatır ve programı durdurur.

# 2. get() Metodu ile Güvenli Erişim:
print(sunucu.get("port"))         # 8080
print(sunucu.get("dns"))          # None (Hata vermez, None döner)
print(sunucu.get("dns", "8.8.8.8")) # "8.8.8.8" (Anahtar yoksa varsayılan değer döner)
```

## 3. Görünüm Nesneleri: `keys()`, `values()`, `items()`

Bu metotlar sözlüğe bağlı dinamik görünüm nesneleri (_view objects_) döndürür. Sözlük güncellendiğinde bu nesneler de otomatik olarak güncellenir.

```Python
stok = {"kod_a": 50, "kod_b": 20, "kod_c": 100}

# keys(): Yalnızca anahtarları döndürür
print(stok.keys())
# Çıktı: dict_keys(['kod_a', 'kod_b', 'kod_c'])

# values(): Yalnızca değerleri döndürür
print(stok.values())
# Çıktı: dict_values([50, 20, 100])

# items(): Her bir (anahtar, değer) çiftini demet (tuple) olarak döndürür
print(stok.items())
# Çıktı: dict_items([('kod_a', 50), ('kod_b', 20), ('kod_c', 100)])
```

## 4. Eleman Ekleme ve Güncelleme

```Python
profil = {"kullanici": "sistem_yoneticisi", "seviye": 2}

# 1. Yeni anahtar atayarak ekleme:
profil["eposta"] = "admin@sistem.local"

# 2. Mevcut anahtarı güncelleme:
profil["seviye"] = 3

# 3. update() metodu ile çoklu ekleme / güncelleme:
profil.update({"seviye": 4, "aktif": True})
print(profil)
# {'kullanici': 'sistem_yoneticisi', 'seviye': 4, 'eposta': 'admin@sistem.local', 'aktif': True}

# 4. setdefault() Metodu:
# Anahtar varsa mevcut değerini döner; anahtar yoksa ekler ve verilen varsayılanı atar.
profil.setdefault("seviye", 1)   # 'seviye' zaten 4 olduğu için dokunmaz, 4 döner
profil.setdefault("rol", "root") # 'rol' olmadığı için ekler ve "root" yapar
```

## 5. Eleman Silme Yöntemleri

```Python
yapilandirma = {
    "host": "localhost",
    "port": 3306,
    "kullanici": "db_user",
    "parola": "gizli123",
    "timeout": 60
}

# 1. pop(anahtar[, varsayilan]): Belirtilen anahtarı siler ve DEĞERİNİ geriye döndürür
silinen_parola = yapilandirma.pop("parola")
print(f"Silinen: {silinen_parola}")  # "gizli123"

# 2. popitem(): Son eklenen (anahtar, değer) ikilisini siler ve TUPLE olarak döndürür
son_eklenen = yapilandirma.popitem()
print(f"Silinen çift: {son_eklenen}")  # ('timeout', 60)

# 3. del deyimi: Anahtarı doğrudan siler veya sözlüğü tamamen bellekten kaldırır
del yapilandirma["host"]
# del yapilandirma  # Sözlüğü tamamen siler

# 4. clear(): Sözlüğün içini tamamen boşaltır
yapilandirma.clear()
print(yapilandirma)  # {}
```

## 6. Sözlükler Üzerinde Döngüler (Loops)

```Python
notlar = {"Matematik": 85, "Fizik": 90, "Kimya": 78}

# 1. Varsayılan döngü (Yalnızca anahtarlar üzerinde gezinir):
for ders in notlar:
    print(ders)

# 2. Yalnızca değerler üzerinde gezinme:
for not_degeri in notlar.values():
    print(not_degeri)

# 3. Hem anahtar hem değere aynı anda erişme (En yaygın yöntem):
for ders, not_degeri in notlar.items():
    print(f"Ders: {ders} -> Not: {not_degeri}")
```

## 7. İç İçe Sözlükler (Nested Dictionaries)

Bir sözlüğün değeri başka bir sözlük olabilir. Bu hiyerarşik verileri (JSON yapıları gibi) modellemek için idealdir:

```Python
sistem_kullanicilari = {
    "kullanici_101": {
        "ad": "Servis Hesabı",
        "yetki": "okuma"
    },
    "kullanici_102": {
        "ad": "Yönetici Hesabı",
        "yetki": "tam"
    }
}

# İç içe verilere erişim:
print(sistem_kullanicilari["kullanici_101"]["ad"])     # "Servis Hesabı"
print(sistem_kullanicilari["kullanici_102"]["yetki"])  # "tam"
```

## 8. Sözlük Kopyalama

`sozluk_b = sozluk_a` işlemi yeni bir sözlük üretmez; yalnızca aynı bellek adresini işaret eder. Bağımsız kopya oluşturmak için `copy()` veya `dict()` kullanılır:

```Python
orijinal = {"a": 1, "b": 2}

# Yüzeysel (shallow) kopya oluşturma:
kopya_1 = orijinal.copy()
kopya_2 = dict(orijinal)

kopya_1["a"] = 99
print(orijinal["a"])  # 1 (Orijinal sözlük değişmez)
```

## 9. Tüm Sözlük Metotları Özeti Tablosu

|**Metot**|**Görevi**|
|---|---|
|`clear()`|Sözlükteki tüm anahtar-değer çiftlerini siler (`{}`).|
|`copy()`|Sözlüğün yüzeysel (_shallow_) kopyasını döner.|
|`fromkeys(keys, value)`|Belirtilen anahtarlardan ve sabit bir değerden yeni sözlük üretir.|
|`get(key, default)`|Anahtarın değerini döner, yoksa hata vermek yerine `default` döner.|
|`items()`|Tüm `(anahtar, değer)` çiftlerini tuple olarak içeren görünüm döner.|
|`keys()`|Sözlükteki tüm anahtarları içeren görünüm döner.|
|`values()`|Sözlükteki tüm değerleri içeren görünüm döner.|
|`pop(key, default)`|Belirtilen anahtarı siler ve değerini döner (yoksa `KeyError` veya `default`).|
|`popitem()`|Son eklenen `(anahtar, değer)` ikilisini siler ve tuple olarak döner.|
|`setdefault(key, default)`|Anahtar varsa değerini döner, yoksa anahtarı `default` değeriyle ekler.|
|`update(other_dict)`|Sözlüğü başka bir sözlük veya anahtar-değer çiftleriyle günceller/genişletir.|
