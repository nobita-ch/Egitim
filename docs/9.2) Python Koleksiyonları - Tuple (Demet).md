Python'da **Demet (`tuple`)**, birden fazla öğeyi tek bir çatı altında sıralı ve sabit tutmak için kullanılan koleksiyon veri yapısıdır.

- **Sıralıdır (Ordered):** Elemanların belirli bir sırası ve 0 tabanlı indeksi vardır.
    
- **Değiştirilemezdir (Immutable):** Oluşturulduktan sonra eleman eklenemez, silinemez veya güncellenemez.
    
- **Yinelenen Elemanlara İzin Verir:** Aynı değere sahip birden çok öğe barındırabilir.
    
- **Farklı Veri Tiplerini Destekler:** Aynı demet içinde `int`, `str`, `bool` ve `list` bir arada tutulabilir.
    

## 1. Demet Tanımlama Yöntemleri


```Python
# Standart yuvarlak parantez ile:
meyveler = ("elma", "muz", "kiraz")

# Parantez kullanmadan da tanımlanabilir (Tuple Packing):
sayilar = 10, 20, 30

# tuple() kurucusu ile tanımlama:
renkler = tuple(("kırmızı", "yeşil", "mavi"))

# Eleman sayısını (uzunluk) öğrenme:
print(len(meyveler))  # 3
```

> **Kritik Kural (Tek Elemanlı Demet):**
> 
> Tek bir elemandan oluşan bir demet oluştururken öğenin sonuna mutlaka **virgül (`,`)** konulmalıdır. Aksi halde Python bunu parantez içindeki düz bir veri tipi (`str`, `int` vb.) olarak algılar.
> 
> Python
> 
> ```
> dogru_demet = ("elma",)
> print(type(dogru_demet))  # <class 'tuple'>
> 
> hatali_demet = ("elma")
> print(type(hatali_demet))  # <class 'str'>
> ```

## 2. Elemanlara Erişme ve Dilimleme (Slicing)

Liste indeksleme kuralları demetler için de birebir geçerlidir:


```Python
diller = ("Python", "C++", "Rust", "Go", "Java")

print(diller[0])    # "Python" (İlk eleman)
print(diller[-1])   # "Java" (Son eleman)
print(diller[1:4])  # ('C++', 'Rust', 'Go') (1'den 4. indekse kadar, 4 hariç)
print(diller[::-1]) # ('Java', 'Go', 'Rust', 'C++', 'Python') (Tersten sıralı yeni tuple)
```

## 3. Demet Değerlerini Güncelleme Yolları

Demetler doğrudan değiştirilemez (`demet[0] = "yeni"` yazmak `TypeError` verir). Güncelleme için iki temel yöntem kullanılır:

### Yöntem A: Listeye Dönüştürme (Geçici Çözüm)


```Python
orijinal_demet = ("veri_a", "veri_b", "veri_c")

# Listeye çevir -> Değiştir -> Tekrar Demet yap
gecici_liste = list(orijinal_demet)
gecici_liste[1] = "guncel_veri"
gecici_liste.append("veri_d")
orijinal_demet = tuple(gecici_liste)

print(orijinal_demet)  # ('veri_a', 'guncel_veri', 'veri_c', 'veri_d')
```

### Yöntem B: Birleştirme ile Yeni Demet Üretme (`+=` ve `*`)


```Python
demet1 = (1, 2, 3)
demet2 = (4,)

# İki demeti birleştirme:
yeni_demet = demet1 + demet2  # (1, 2, 3, 4)

# Katsayı ile çoğaltma:
tekrarli = demet1 * 2  # (1, 2, 3, 1, 2, 3)

# Açma (*) operatörü ile yeni tuple içine yerleştirme:
genisletilmis = (*demet1, 100, 200)  # (1, 2, 3, 100, 200)
```

## 4. Demeti Bellekten Silme

Demet içinden tek bir eleman silinemez (`remove` veya `pop` yoktur). Ancak tüm demet nesnesi **`del` deyimi** ile bellekten kaldırılabilir:


```Python
veriler = ("A", "B", "C")
del veriler  # Demet tamamen bellekten silinir
# print(veriler)  # HATA: NameError: name 'veriler' is not defined
```

## 5. Paketleme ve Paketten Çıkarma (Tuple Packing & Unpacking)

Bir demetin elemanlarını ayrı değişkenlere dağıtma işlemine **açma (unpacking)** denir.


```Python
koordinat = (40.7128, -74.0060, 15)

# Birebir eleman eşleşmesi:
enlem, boylam, yukseklik = koordinat
print(enlem)     # 40.7128
print(boylam)    # -74.0060
```

### Yıldız (`*`) Operatörü ile Kalanları Toplama

Değişken sayısı ile demet eleman sayısı uyuşmadığında, `*` operatörü artan tüm elemanları **bir liste halinde** toplar:


```Python
notlar = (90, 85, 70, 60, 95, 100)

# İlk iki elemanı al, kalanları 'digerleri' listesine ata:
birinci, ikinci, *digerleri = notlar
print(birinci)   # 90
print(ikinci)    # 85
print(digerleri) # [70, 60, 95, 100]

# Baştaki ve sondaki elemanı al, aradakileri listeye ata:
ilk, *orta, son = notlar
print(ilk)       # 90
print(orta)      # [85, 70, 60, 95]
print(son)       # 100
```

## 6. Yerleşik Demet Metotları ve Fonksiyonlar

Demetler değiştirilemez olduğu için yalnızca **2 adet** yerleşik metoda sahiptir:

|**Metot**|**Görevi**|**Örnek (d = (10, 20, 10, 30))**|**Sonuç**|
|---|---|---|---|
|`count(x)`|Belirtilen değerin demette kaç kez geçtiğini sayar|`d.count(10)`|`2`|
|`index(x)`|Değerin ilk görüldüğü indeks numarasını verir|`d.index(20)`|`1` (Yoksa `ValueError` fırlatır)|

### Demetlerle Sık Kullanılan Genel Fonksiyonlar:


```Python
rakamlar = (5, 12, 3, 8)

print(len(rakamlar))  # 4 (Eleman sayısı)
print(min(rakamlar))  # 3 (En küçük eleman)
print(max(rakamlar))  # 12 (En büyük eleman)
print(sum(rakamlar))  # 28 (Sayısal elemanların toplamı)
```

## 7. `List` ile `Tuple` Arasındaki Farklar (Neden Tuple Kullanılır?)

|**Özellik**|**Liste (list)**|**Demet (tuple)**|
|---|---|---|
|**Sözdizimi**|Köşeli parantez `[]`|Yuvarlak parantez `()`|
|**Değiştirilebilirlik**|Değiştirilebilir (_Mutable_)|Değiştirilemez (_Immutable_)|
|**Bellek Tüketimi**|Daha fazla bellek harcar|Daha az bellek tüketir|
|**İşlem Hızı**|Daha yavaş|Sabit yapısı sayesinde daha hızlıdır|
|**Kullanım Amacı**|Dinamik, sürekli güncellenen veriler|Sabit kalan konfigürasyonlar, koordinatlar|
|**Sözlük Anahtarı Olma**|Anahtar (_dict key_) **olamaz**|Değişmez olduğu için anahtar **olabilir**|

**İç İçe Değiştirilebilir Eleman İstisnası:**

Tuple değiştirilemez olsa da, içinde bir liste (`list`) barındırıyorsa o listenin elemanları değiştirilebilir:

```Python
ozel_demet = ("Sabit Veri", [1, 2, 3])
ozel_demet[1].append(4)  # Bu işlem geçerlidir!
print(ozel_demet)        # ('Sabit Veri', [1, 2, 3, 4])
```
