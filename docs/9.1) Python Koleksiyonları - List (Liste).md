Python'da **liste (`list`)**, birden fazla veriyi tek bir çatı altında tutmak için kullanılan en temel veri yapısıdır.

- **Sıralıdır (Ordered):** Elemanlar eklenme sırasını korur ve indeks numaraları ile yönetilir.
    
- **Değiştirilebilirdir (Mutable):** Liste oluşturulduktan sonra elemanlar güncellenebilir, yeni eleman eklenebilir veya silinebilir.
    
- **Yinelenen Elemanlara İzin Verir (Allows Duplicates):** İndeks tabanlı çalıştığı için aynı değere sahip birden fazla eleman barındırabilir.
    
- **Farklı Veri Tiplerini Destekler:** Tek bir liste içinde `int`, `str`, `bool` veya başka bir `list` bir arada bulunabilir.
    

## 1. Liste Tanımlama Yöntemleri



```Python
# Köşeli parantez ile standart tanımlama:
meyveler = ["elma", "muz", "kiraz"]

# Farklı veri tiplerini bir arada tutma:
karmasik_liste = ["veri", 100, True, 3.14]

# list() kurucu (constructor) fonksiyonu ile tanımlama:
sayilar = list((10, 20, 30))

# Eleman sayısını (uzunluk) öğrenme:
print(len(meyveler))  # 3
```

## 2. Elemanlara Erişme ve Dilimleme (Slicing)

Liste elemanlarına 0 tabanlı pozitif indekslerle veya sondan başlayan negatif indekslerle erişilir.



```Python
programlar = ["Python", "Java", "C++", "Rust", "Go", "Kotlin"]

# Tek elemana erişim
print(programlar[0])   # "Python" (İlk eleman)
print(programlar[-1])  # "Kotlin" (Son eleman)

# Aralık dilimleme: liste[start:stop:step] (stop değeri hariçtir)
print(programlar[1:4])   # ['Java', 'C++', 'Rust']
print(programlar[:3])    # ['Python', 'Java', 'C++'] (Baştan 3. indekse kadar)
print(programlar[3:])    # ['Rust', 'Go', 'Kotlin'] (3. indeksten sona kadar)
print(programlar[-3:-1]) # ['Rust', 'Go']
print(programlar[::-1])  # Listeyi tamamen tersten sıralar
```

## 3. Eleman Güncelleme



```Python
renkler = ["kırmızı", "mavi", "sarı", "yeşil"]

# Tek bir elemanı güncelleme:
renkler[1] = "beyaz"  # ['kırmızı', 'beyaz', 'sarı', 'yeşil']

# Aralık düzeyinde çoklu güncelleme:
renkler[1:3] = ["siyah", "turuncu"]
print(renkler)  # ['kırmızı', 'siyah', 'turuncu', 'yeşil']
```

## 4. Eleman Ekleme ve Listeleri Birleştirme



```Python
veriler = ["A", "B"]

# 1. append(öğe): Listenin SONUNA tek bir eleman ekler
veriler.append("C")  # ['A', 'B', 'C']

# 2. insert(indeks, öğe): Belirtilen indekse araya sokar (sağdakiler kayar)
veriler.insert(1, "X")  # ['A', 'X', 'B', 'C']

# 3. extend(iterable): Başka bir listeyi/koleksiyonu mevcut listeye ulayarak genişletir
ek_liste = ["D", "E"]
veriler.extend(ek_liste)  # ['A', 'X', 'B', 'C', 'D', 'E']

# 4. '+' Operatörü ile yeni birleşik liste üretme:
liste1 = [1, 2]
liste2 = [3, 4]
birlesik = liste1 + liste2  # [1, 2, 3, 4]

# 5. Açma (*) Operatörü ile birleştirme (Python 3.5+):
yeni_birlesik = [*liste1, *liste2]  # [1, 2, 3, 4]
```


`append()` vs `extend()` Farkı:

 ```python
a = [1, 2]
a.append([3, 4])  # [1, 2, [3, 4]] -> İç içe liste ekler

 b = [1, 2]
 b.extend([3, 4])  # [1, 2, 3, 4]   -> Elemanları tek tek ekler
 ```


## 5. Eleman Silme Yöntemleri


```Python
sehirler = ["Ankara", "İstanbul", "İzmir", "Bursa", "Antalya"]

# 1. remove(değer): Değeri eşleşen İLK elemanı siler (Yoksa ValueError verir)
sehirler.remove("İstanbul")

# 2. pop([indeks]): Belirtilen indeksteki elemanı siler VE geriye döndürür
silinen = sehirler.pop(1)  # 1. indeksteki "İzmir" silinir ve silinen değişkenine atanır
son_silinen = sehirler.pop()  # Parametresiz çağrılırsa en son elemanı ("Antalya") atar

# 3. del deyimi: İndekse, aralığa göre siler veya tüm listeyi bellekten kaldırır
del sehirler[0]      # 0. indeksteki elemanı siler
# del sehirler       # Listeyi bellekten tamamen siler

# 4. clear(): Listenin içini boşaltır (Liste nesnesi bellekte boş [] olarak kalır)
sehirler.clear()
```

## 6. Liste Kopyalama (Referans vs Kopya)

Bir listeyi `liste2 = liste1` şeklinde eşitlerseniz **yeni bir liste oluşmaz**; sadece aynı bellek adresine yeni bir referans atanır. Birinde yapılan değişiklik diğerini de bozar. Bağımsız kopya için şu yöntemler kullanılır:



``` Python
orijinal = [1, 2, 3]

# 1. copy() metodu:
kopya1 = orijinal.copy()

# 2. list() kurucusu:
kopya2 = list(orijinal)

# 3. Dilimleme [:] operatörü:
kopya3 = orijinal[:]
```

## 7. Liste Metotları ve Yardımcı Fonksiyonlar Tablosu

|**Metot / Fonksiyon**|**Tür**|**Açıklama**|**Davranış / Önemli Detay**|
|---|---|---|---|
|`append(x)`|Metot|Listenin sonuna tek bir eleman ekler.|Orijinal listeyi günceller (_in-place_).|
|`extend(iterable)`|Metot|Bir dizinin tüm elemanlarını sona ekler.|Listeyi genişletir.|
|`insert(i, x)`|Metot|`i` indeksine `x` elemanını yerleştirir.|Diğer elemanları sağa öteler.|
|`remove(x)`|Metot|Değeri `x` olan ilk elemanı siler.|Değer listede yoksa `ValueError` verir.|
|`pop([i])`|Metot|`i` indeksindeki elemanı siler ve döndürür.|İndeks verilmezse son elemanı çıkarır.|
|`clear()`|Metot|Listedeki tüm elemanları temizler.|Sonuç: `[]`.|
|`index(x)`|Metot|`x` değerinin ilk bulunduğu indeksi döner.|Bulamazsa `ValueError` fırlatır.|
|`count(x)`|Metot|`x` değerinin listede kaç defa geçtiğini sayar.|Yoksa `0` döner (hata vermez).|
|`sort()`|Metot|Listeyi yerinde (_in-place_) sıralar.|Geriye `None` döner, listeyi değiştirir.|
|`reverse()`|Metot|Listenin sırasını yerinde tersine çevirir.|Geriye `None` döner.|
|`copy()`|Metot|Listenin yüzeysel (_shallow_) kopyasını alır.|İç içe listeler hariç bağımsız kopya üretir.|
|`len(liste)`|Fonksiyon|Listenin toplam eleman sayısını verir.|Yerleşik genel fonksiyondur.|
|`min(liste)` / `max(liste)`|Fonksiyon|En küçük veya en büyük elemanı bulur.|Karşılaştırılabilir tiplerde çalışır.|
|`sorted(liste)`|Fonksiyon|Orijinal listeyi bozmadan sıralı yeni kopya verir.|`liste.sort()`tan farkı yeni liste üretmesidir.|

## 8. Sıralama İşlemleri (`sort()` vs `sorted()`)



```Python
sayilar = [40, 10, 50, 20]

# Küçükten büyüğe sıralama (orijinal liste değişir):
sayilar.sort()  # [10, 20, 40, 50]

# Büyükten küçüğe sıralama:
sayilar.sort(reverse=True)  # [50, 40, 20, 10]

# Büyük/küçük harf duyarsız sıralama (key parametresi):
metinler = ["muz", "Elma", "armut", "Kiraz"]
metinler.sort(key=str.lower)
print(metinler)  # ['armut', 'Elma', 'Kiraz', 'muz']

# Orijinali bozmadan yeni sıralı liste alma:
ham_liste = [5, 2, 9, 1]
sirali_yeni = sorted(ham_liste)  # sirali_yeni: [1, 2, 5, 9], ham_liste aynı kalır
```

Not: Python da diğer dillerde olduğu gibi doğrudan temel yerleşik dizi (array) türü yoktur. ancak bunun yerine çok yönlü listeler kullanılabilir. 
(`array` modülü vardır ama kısıtlı bir yaklaşıma sahiptir.)
