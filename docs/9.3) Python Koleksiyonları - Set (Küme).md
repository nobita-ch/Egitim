Python'da **Küme (`set`)**, matematikteki küme mantığıyla çalışan, benzersiz elemanlardan oluşan koleksiyon veri yapısıdır.

- **Sırasızdır (Unordered):** Elemanların belirli bir indeksi veya sabit sıralaması yoktur; ekrana basıldığında sıra değişebilir.
    
- **İndekslenemez (Unindexed):** `kume[0]` şeklinde indeksle veya dilimlemeyle (`kume[1:3]`) elemana erişilemez.
    
- **Yinelenen Eleman Kabul Etmez (Unique Elements):** Aynı elemandan birden fazla bulunamaz; tekrar eden veriler otomatik olarak elenir.
    
- **Kısmi Değiştirilebilirlik:** Kümenin içine yeni eleman eklenebilir veya silinebilir; ancak küme içindeki mevcut bir elemanın doğrudan içeriği değiştirilemez.
    
- **Sadece Değiştirilemez (Hashable) Elemanlar Alabilir:** Küme içine `int`, `float`, `str`, `tuple` konulabilir; ancak `list`, `dict` veya başka bir `set` **eklenemez**.
    

## 1. Küme Tanımlama Yöntemleri


```Python
# Süslü parantez ile standart tanımlama:
sayilar = {1, 5, 7, 9, 3}
karisik_kume = {"veri", 100, (1, 2), True}

# set() kurucusu ile tanımlama:
renkler = set(("kırmızı", "yeşil", "mavi"))

# Yinelenen elemanların otomatik elenmesi:
tekrarli = {1, 2, 2, 3, 3, 3}
print(tekrarli)  # {1, 2, 3}
```

> **Kritik Kural (Boş Küme Tanımlama):**
> 
> Boş süslü parantez `{}` Python'da **boş bir sözlük (`dict`)** üretir. Boş küme oluşturmak için mutlaka `set()` kullanılmalıdır:
> 
> Python
> 
> ```
> bos_sozluk = {}
> print(type(bos_sozluk))  # <class 'dict'>
> 
> bos_kume = set()
> print(type(bos_kume))   # <class 'set'>
> ```

## 2. Boole Değerleri (`True` / `1` ve `False` / `0` Çakışması)

Python'da `True` ile `1`, `False` ile `0` aynı mantıksal değere karşılık geldiği için bir kümede aynı anda yer alamazlar (hangisi önce yazıldıysa o tutulur):


```Python
kume = {"elma", True, 1, 2, False, 0}
print(kume)  # {False, True, 2, 'elma'} (1 ve 0 elendi)
```

## 3. Küme Elemanlarına Erişme ve Varlık Kontrolü

İndeksleme desteklenmediği için elemanlara döngüler, `in` operatörü veya dönüştürme yöntemleriyle erişilir:

```Python

diller = {"Python", "C++", "Rust"}

# 1. in operatörü ile hızlı kontrol (Kümelerde O(1) karmaşıklıkla çok hızlıdır):
print("Python" in diller)  # True

# 2. for döngüsü ile gezinme:
for eleman in diller:
    print(eleman)

# 3. Listeye veya Demete çevirerek indekse erişme:
liste_hali = list(diller)
print(liste_hali[0])
```

## 4. Eleman Ekleme Yöntemleri


```Python
kume = {"A", "B"}

# 1. add(): Tek bir eleman ekler
kume.add("C")
print(kume)  # {'A', 'B', 'C'}

# 2. update(): Başka bir kümeyi, listeyi veya demeti mevcut kümeye ekler
kume.update(["D", "E"], {"F"})
print(kume)  # {'A', 'B', 'C', 'D', 'E', 'F'}
```

## 5. Eleman Silme Yöntemleri


```Python
veriler = {"elma", "muz", "kiraz", "portakal"}

# 1. remove(x): Elemanı siler. Eleman kümede yoksa KeyError fırlatır!
veriler.remove("muz")

# 2. discard(x): Elemanı siler. Eleman kümede yoksa HATA VERMEZ (güvenlidir).
veriler.discard("armut")  # 'armut' olmasa da program çökmez

# 3. pop(): Rastgele bir elemanı siler ve silinen elemanı geriye döndürür.
silinen = veriler.pop()
print(f"Silinen: {silinen}")

# 4. clear(): Kümenin içindeki tüm elemanları boşaltır.
veriler.clear()  # set()

# 5. del deyimi: Kümeyi bellekten tamamen siler.
del veriler
```

## 6. Matematiksel Küme İşlemleri ve Operatörleri

Kümeler arasındaki birleşim, kesişim ve fark işlemleri hem **metotlarla** hem de **operatör sembolleriyle** yapılabilir:

|**İşlem**|**Metot**|**Operatör**|**Açıklama**|
|---|---|---|---|
|**Birleşim**|`kume1.union(kume2)`|`kume1 \| kume2`|Her iki kümedeki tüm benzersiz elemanları birleştirir.|
|**Kesişim**|`kume1.intersection(kume2)`|`kume1 & kume2`|Yalnızca her iki kümede de ortak olan elemanları alır.|
|**Fark**|`kume1.difference(kume2)`|`kume1 - kume2`|İlk kümede olup ikinci kümede olmayan elemanları alır.|
|**Simetrik Fark**|`kume1.symmetric_difference(kume2)`|`kume1 ^ kume2`|Ortak elemanlar hariç diğer tüm elemanları alır.|

### Kod Örnekleri:


```Python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

# Birleşim (Union - |)
print(A | B)                    # {1, 2, 3, 4, 5, 6}
print(A.union(B))

# Kesişim (Intersection - &)
print(A & B)                    # {3, 4}
print(A.intersection(B))

# Fark (Difference - -)
print(A - B)                    # {1, 2} (A'da olup B'de olmayanlar)
print(B - A)                    # {5, 6} (B'de olup A'da olmayanlar)

# Simetrik Fark (Symmetric Difference - ^)
print(A ^ B)                    # {1, 2, 5, 6} (Ortak olan 3 ve 4 hariç)
```

## 7. Küme Karşılaştırma ve Mantıksal İlişki Metotları


```Python
X = {1, 2}
Y = {1, 2, 3, 4}

# 1. issubset(): Alt kümesi mi? (X <= Y)
print(X.issubset(Y))    # True

# 2. issuperset(): Kapsayan küme mi? (Y >= X)
print(Y.issuperset(X))  # True

# 3. isdisjoint(): Kümeler tamamen ayrık mı? (Hiç ortak elemanı yok mu?)
print(X.isdisjoint({5, 6}))  # True (Ortak eleman yok)
print(X.isdisjoint(Y))       # False (1 ve 2 ortak)
```

## 8. Dondurulmuş Kümeler: `frozenset`

Normal kümeler değiştirilebilir (`mutable`) olduğu için sözlüklerde anahtar (**dict key**) veya başka bir kümenin elemanı olarak kullanılamazlar. Değiştirilemez bir küme gerekiyorsa **`frozenset`** kullanılır:

```Python
sabit_kume = frozenset([1, 2, 3])
# sabit_kume.add(4)  # HATA: AttributeError verir

# frozenset sözlük anahtarı olarak kullanılabilir:
sozluk = {sabit_kume: "Küme Verisi"}
print(sozluk[sabit_kume])  # "Küme Verisi"
```
